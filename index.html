Succubuns

Type your character’s name, then paste their ID. The ID is the part of your character’s page link after /character/, for example MYO-12345. Each character gets a Pets tile, labeled with the name once you add one.

Baobears

Paste an image link to use for the My Baobears tile. Leave it blank to keep the default.

CupidCats

Paste the full link to your Featured Pet, starting with https://. You can copy it from your browser’s address bar while viewing the pet. The tile only appears once you add this link. Paste an image link in the second box if you want a different tile image, such as a picture of your particular pet.

Export / import

Exporting copies your settings as text, so you can paste them into another browser. That text contains your personal details, so keep it private and don’t post it in the repo or anywhere public.

Image links must start with https://. To copy one, right-click the image and choose Copy Image Address. On a phone, press and hold the image. If a box turns red, check that the link starts with https:// and is copied in full.
